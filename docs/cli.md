## boxvector

```
Boxvector generates and manages BIRD 2/3 BGP configuration (fork of Pathvector).

Usage:
  boxvector [command]

Available Commands:
  birdsh      Lightweight BIRD shell
  completion  Generate the autocompletion script for the specified shell
  config      Export configuration, optionally sanitized with logknife
  dump        Dump configuration
  generate    Generate router configuration
  help        Help about any command
  match       Find common IXPs for a given ASN
  optimizer   Start optimization daemon
  status      Show protocol status
  version     Show version information
  web         Run the web UI

Flags:
  -c, --config string   YAML configuration file (default "/etc/boxvector/boxvector.yml")
  -d, --dry-run         Don't modify configuration
  -h, --help            help for boxvector
      --lock string     Lock file (check disabled if empty)
  -n, --no-configure    Don't configure BIRD
  -t, --trace           Show trace log messages
  -v, --verbose         Show verbose log messages

Use "boxvector [command] --help" for more information about a command.
```

## boxvector web

```
Run the web UI

Usage:
  boxvector web [flags]
  boxvector web [command]

Available Commands:
  passwd      Create a web user or change its password

Flags:
      --allow-public       allow listening on a non-loopback address without TLS (default true)
      --auth-file string   user file (user:bcrypt per line, mode 600) (default "/etc/boxvector/web.users")
      --file-auth          sign in with --auth-file users (bcrypt) instead of the server accounts
  -h, --help               help for web
      --listen string      listen address (host:port) (default "0.0.0.0:6969")
      --state-dir string   directory for snapshots and history (default "/var/lib/boxvector")
      --tls-cert string    TLS certificate file (enables HTTPS)
      --tls-key string     TLS key file
      --trust-proxy        trust X-Forwarded-For/Proto from a reverse proxy

Global Flags:
  -c, --config string   YAML configuration file (default "/etc/boxvector/boxvector.yml")
  -d, --dry-run         Don't modify configuration
      --lock string     Lock file (check disabled if empty)
```
