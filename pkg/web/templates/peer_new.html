Custom policy · optional, compiled to BIRD for you (pre-import-filter / pre-export)

Rule syntax
One rule per line. only <cond> keeps only matching routes and rejects the rest. reject (or suppress) <cond> drops matching routes. med N, prepend N, add-community A:B, add-large-community A:B:C, each with an optional when <cond>.
Conditions: origin ASN.., first-as ASN.., path-contains ASN.., path-len <|<=|>|>=|= N, path 65001 * 65010 (* any ASNs, ? one), prefix 10.0.0.0/8 ge 16 le 24, community A:B, large-community A:B:C, ipv4, ipv6. Combine with and / or (not both on one line) and negate with not. ASN ranges: 64512-65534. Rules never accept outright, so the RPKI, bogon and IRR filters still apply.
